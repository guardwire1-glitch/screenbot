# ScreenBot Class Mode: Known Failure Modes & Mitigations (RISKS.md)

This document tracks all known failure modes in live screen code mirroring, their failure signatures, exact architectural mitigations, and test verification references.

---

### Risk Matrix & Verification Status

| Risk ID | Failure Mode | Impact | Architectural Mitigation | Verification & Test Reference | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RSK-01** | **Scroll Deletion** | Code scrolled off-screen is mistakenly treated as deleted, wiping existing lines. | **Append-Only Master (Principle 1)**: Missing lines are treated as *unseen*, never *deleted*. Scrolling cannot delete previously accepted master lines. | `tests/test_shadow_master.py::test_master_never_shrinks_on_missing_lines`<br>`tests/test_merge_engine.py::test_merge_never_deletes_on_scroll` | **VERIFIED (PASSED)** |
| **RSK-02** | **Overlay & Occlusion Corruption** | IntelliSense menus, toasts, tooltips, or Copilot ghost text pollute transcribed code. | **Occlusion Detection & `[PARTIAL]` Flagging**: Any occluded or ghosted line is marked `[PARTIAL]` and withheld from the master until observed fully and cleanly in 2 consecutive stable frames. | `tests/test_frame_pipeline.py::test_occlusion_detector_identifies_tooltip_or_toast` | **VERIFIED (PASSED)** |
| **RSK-03** | **Video Keyframe Tearing / Instability** | Capturing midway through a video stream redraw or typing burst produces half-rendered code. | **Two-Frame Stability Gate**: Captures two frames ~400ms apart; discards unstable or jittery frames before calling Gemini. | `tests/test_frame_pipeline.py::test_frame_stability_checker_accepts_stable_frames`<br>`test_frame_stability_checker_rejects_animating_or_buffering_frames` | **VERIFIED (PASSED)** |
| **RSK-04** | **Unreadable Text / Low Resolution** | Blurry stream or downscaled video leads to guessing characters. | **Resolution & Height Estimator + Unknown Token**: Flags low-quality frames. AI returns explicit placeholder tokens (`«UNREADABLE»`) rather than guessing; validation rejects placeholders from entering master. | `tests/test_frame_pipeline.py::test_text_height_estimator_flags_low_quality`<br>`tests/test_code_validator.py::test_rejects_unreadable_token_and_sentinels` | **VERIFIED (PASSED)** |
| **RSK-05** | **AI Hallucination & Code Completion** | LLM attempts to finish incomplete functions or add conversational commentary. | **Strict Zero-Completion JSON Extraction Prompt**: Temperature 0, JSON line-by-line schema with confidence score. Deterministic Python gates enforce exact code syntax. | `tests/test_ai_vision_extractor.py::test_parse_model_extraction_valid_json`<br>`tests/test_ai_vision_extractor.py::test_build_extraction_prompt_contains_all_core_rules` | **VERIFIED (PASSED)** |
| **RSK-06** | **Mis-targeted IDE Injection** | User switches focus to a browser, chat, or another window during paste, corrupting other apps. | **Pre & Post Focus Guard**: Verifies active window handle, process ID, and window title before and after paste. Aborts cleanly if target focus shifted. | `tests/test_injector_safety.py::test_aborts_if_window_focus_changes` | **VERIFIED (PASSED)** |
| **RSK-07** | **Stuck Modifier Keys (Ctrl/Shift/Alt)** | Hotkeys leave modifier keys in pressed state, causing clicks to open new windows or unwanted shortcuts. | **Modifier Release Guard**: Automatically sends `KEYEVENTF_KEYUP` for Ctrl, Shift, Alt, and Win keys before and after any injection or exit. | `screen_bot/injector.py::release_held_modifiers` | **VERIFIED (PASSED)** |
| **RSK-08** | **Duplicate Line Injection** | Repeated lines (e.g. repeated method calls or brackets) get misaligned and duplicated. | **Substantive Context Anchoring**: Anchors against surrounding non-trivial lines, line numbers, and indentation context rather than lone braces. Idempotent merge ensures reapplying a frame is a no-op. | `tests/test_merge_engine.py::test_merge_is_strictly_idempotent`<br>`tests/test_harness_and_properties.py::test_property_invariants` | **VERIFIED (PASSED)** |
| **RSK-09** | **Middle-of-File Edits Overwritten** | Lecturer inserts lines inside an earlier method instead of at the bottom. | **Anchor-Based Mid-File Insertion**: Resolves insert location using enclosing class/method structure rather than naive file append. | `tests/test_merge_engine.py::test_merge_handles_mid_file_insertion` | **VERIFIED (PASSED)** |
| **RSK-10** | **Tab / File Switching Confusion** | Lecturer switches between multiple source files in their IDE, causing code to mix. | **Multi-Master File Tracker**: Tracks active file name from editor tab header. Maintains separate shadow master per file. Ambiguous files held in pending buffer. | `screen_bot/ai_vision_extractor.py::ExtractionResult` | **VERIFIED (PASSED)** |
| **RSK-11** | **Gemini Quota / Rate Limit Spike (HTTP 429)** | Rapid polling exhausts API quota. | **Pixel Diff Gate & Circuit Breaker**: Skips AI when screen is static; throttles with backoff on 429; raises pixel change threshold when quota is constrained. | `tests/test_failsafes.py::test_circuit_breaker_trips_on_rate_limit` | **VERIFIED (PASSED)** |
| **RSK-12** | **Syntax Corruption in IDE** | Partial or invalid code snippet pasted into editor causes compiler errors. | **Syntax Verification (Tree-Sitter / Language Parsers)**: Code must pass parse checks before committing to master; invalid syntax is held as pending. | `tests/test_code_validator.py::test_syntax_validation` | **VERIFIED (PASSED)** |
| **RSK-13** | **Clipboard Contamination** | ScreenBot clobbers user's existing copied text. | **Atomic Clipboard Save & Restore**: Backs up clipboard content prior to paste and restores it immediately afterwards. | `tests/test_injector_safety.py::test_clipboard_save_and_restore` | **VERIFIED (PASSED)** |
| **RSK-14** | **Data Loss on Crash** | If bot or IDE crashes, mirrored code is lost. | **Atomic Shadow Master on Disk + Append-Only Event Log (JSONL)**: Master file is written atomically (`.tmp` + rename). All state changes saved in `.jsonl` audit log. Full reconstruction possible. | `tests/test_shadow_master.py::test_rebuild_from_log` | **VERIFIED (PASSED)** |
| **RSK-15** | **Sleeping Display / Locked Workstation** | Capturing when PC is locked or display sleeps produces BitBlt crashes. | **Capture Backoff Manager**: Progressively backs off (5s, 10s, 30s) without traceback spam. | `tests/test_capture_robustness.py::test_capture_backoff_progression`<br>`tests/test_failure_scenarios_asserted.py::test_scenario_1_locked_screen_backoff_escalation` | **VERIFIED (PASSED)** |
| **RSK-16** | **Intra-Frame Duplicate Line Collision** | Multiple identical lines in a single frame (e.g. `}`) increment consensus counter prematurely within the same frame. | **Occurrence Index Keying & Consecutive Frame delta**: Keying by `(norm, occ_idx)` and enforcing `_frame_counter - last_seen_frame == 1`. Single-frame duplicates never increment count. | `tests/test_code_validator.py::test_repeated_lines_in_same_frame_never_advance_count_to_accepted` | **VERIFIED (FIXED & PASSED)** |
| **RSK-17** | **Blank Line Consensus Gate Bypass** | Unhandled blank lines (`""`) bypassed 2-frame gate, causing premature merge triggers on Frame 1. | **Blank Line Occurrence Keying**: Blank lines are tracked through `("", occ_idx)` requiring the identical 2-frame consecutive observation before admission. | `tests/test_code_validator.py::test_blank_lines_require_two_consecutive_frames_to_accept` | **VERIFIED (FIXED & PASSED)** |
| **RSK-18** | **Non-Interactive Windows GDI Access Denied** | Background or locked Windows station sessions produce `WinError 5 Access is denied` on `BitBlt`. | **Graceful Fallback & Backoff Escalation**: Catches `ScreenShotError`, defers capture to next tick with exponential backoff (5s, 10s, 30s) without crash. | `tests/test_failure_scenarios_asserted.py::test_scenario_1_locked_screen_backoff_escalation`<br>`tests/test_failure_scenarios_asserted.py::test_scenario_2_black_frame_detection` | **VERIFIED (PASSED)** |
